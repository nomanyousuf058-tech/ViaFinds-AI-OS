# 06 PHASE 2 CONTENT STRATEGY

## Overview
The Brain no longer assumes every product requires a "Review" article. It dynamically evaluates the required format based on the business goals and context.

## Implementation
- `Task Engine` execution allows the Brain to identify content gaps and output specific format recommendations (e.g., Comparison, Tutorial, Buying Guide, Problem/Solution).
- The opportunity object captures the `recommended_action`, ensuring the content type is preserved for future automated execution (Phase 3).
