# Dashboard Specification

## Goal

The dashboard is the Control Center of ViaFinds AI OS.

Everything must be visible here.

Nothing important should require opening multiple pages.

The dashboard must allow monitoring, approval, reporting, debugging, and automation control.

Never approve raw JSON.

Never approve incomplete content.
