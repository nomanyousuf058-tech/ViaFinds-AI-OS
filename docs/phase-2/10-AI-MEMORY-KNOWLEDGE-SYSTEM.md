# Memory Layers

ViaFinds AI OS contains four memory layers.

---

# Layer 1
## Working Memory

Purpose

Temporary memory for current task.

Stores

- Current workflow
- Current prompt
- AI responses
- Temporary files
- Current trend
- Current product
- Current blog
- Current tool

Lifetime

Until workflow finishes.

---

# Layer 2
## Short-Term Memory

Purpose

Remember recent activities.

Stores

Recent

- Products
- Blogs
- Tools
- Videos
- Social posts
- Errors
- Fixes

Retention

7–30 days.
