# Trend Intelligence System

---

# Goal

The Trend Intelligence System is the brain that discovers opportunities before competitors.

It continuously monitors the internet to identify:

- Trending products
- Trending tools
- Viral topics
- Customer problems
- Seasonal demand
- Affiliate opportunities

The system works automatically or manually.

---

# Run Modes

## Manual Mode

Administrator clicks

Run Trend Analysis

The system immediately scans all sources.

---

## Automatic Mode

Runs every few hours.

Default

Every 6 hours.

Administrator can change schedule.
